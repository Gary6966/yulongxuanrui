# 御龙悬睿 CRTC2026 中期制作记录

## 主控板的初步使用

我们把前期重点放在STM32的基础使用上，先熟悉供电、引脚和程序下载，再了解GPIO和PWM。初期目标比较简单，就是用主控控制一个电机，再接上一个轮子，暂时不把手柄和机械爪一起接进来。

主控参考STM32F103C8T6核心板。学习时先看例程的初始化和输出部分，弄清楚哪些引脚控制方向，哪些引脚输出PWM。电机不能直接接在主控引脚上，需要由驱动板带动。

## 一个电机的控制

单电机方案采用TT减速电机和TB6612FNG驱动板。接线先区分电机电源、逻辑电源和地线，再接方向信号及PWM。主控和驱动板需要共地，使能端也要设置正确。逻辑供电要与主控输出电平匹配，不能只照商品图标注的电压连接。

电机没有反应时，先从接线检查起，再看程序。漏接地线、使能端没有设置、接线位置看错，都可能让电机没有动作。检查时一次只改一处，避免接线和程序同时调整以后分不清原因。

正反转先按固定的电机朝向判断。如果方向与预期相反，可以断电调整电机两根线的位置，也可以修改程序中的方向定义，两种办法选一种。PWM先用于观察输出大小和转动之间的关系，不把占空比直接当成实测转速。

## 轮子的安装

轮子参考60毫米麦克纳姆轮。我们先考虑一个轮子和电机的连接，重点看电机轴、联轴器和轮子的固定方式，再考虑四轮的安装位置。

安装时要留出轮子与支架之间的间隙。轮子装得太靠里，可能擦到支架；联轴器装偏，也可能让转动不顺。遇到摩擦声时先断电检查安装，不直接靠增加输出解决。调整位置后还要重新紧固，不能把螺丝松着使用。

四轮安装还涉及左右轮型和电机方向。单个轮子能转，只能说明这一部分的连接基本可行，后面仍要分别检查其他轮位。

## 后面的制作安排

我们按主控、单电机、单轮、四轮底盘的顺序推进，暂时不加入复杂控制。底盘部分先考虑前进和后退，再考虑手柄输入和其他动作。

机械爪参考带舵机的金属夹爪方案，放在底盘之后处理。先了解舵机供电和开合，再考虑装车位置与方块夹持，不把舵机开合直接等同于完成抓取。

后续记录以接线照片、程序文件和动作观察为主。每次调整保留原来的连接和程序，方便出现问题时回头检查。
