# 御龙悬睿 CRTC2026 中期制作记录

本文为初期制作记录草稿，补写经历尚需按实际情况核对。

## 主控板的初步使用

我们前面主要在熟悉STM32，先看了核心板上各个引脚的位置，再跟着资料试着下载基础程序。一开始不太清楚哪些地方需要自己改，基本是对照例程一点点看。现在主要接触了GPIO和PWM，其他功能还没怎么用。

目前没有把整辆车装起来，主要先在桌上接主控和一个电机。我们想先把这一部分弄明白，再接后面的几个电机，不然线多了以后更不好查。

## 一个电机的转动

电机用的是TT减速电机，驱动板参考TB6612FNG。刚开始接线时，主要注意了方向控制和PWM，没有把主控与驱动板之间的地线接完整。程序下载以后电机没反应，我们起初以为是程序的问题，改了几次输出也没看出变化。

后来重新对照接线，发现主控和驱动板需要共地。断电补上连接，再检查驱动板的使能端，才继续试着让电机转动。前面几次没有把接线记清楚，查起来花了些时间。

电机转起来以后，方向和我们原来想的相反。我们把电机固定在同一个朝向看了一下，随后断电调整了电机两根线的位置，没有同时改程序。现在只是在一个电机上试正反转，还没有做整车的前进和后退。

PWM也只是先试着改输出大小。输出比较小时，电机有时没有明显动作，增加以后才转起来。我们还没有测转速，所以这里只能说观察到了转动变化，暂时不清楚具体能控制到什么程度。

## 轮子的安装

我们先试着把一个轮子装到电机上。轮子参考的是60毫米麦克纳姆轮，目前主要看它和电机轴怎么连接，还没把四个轮子一起装好。

装的时候把轮子推得比较靠里，转起来有摩擦声。不装轮子时电机能转，装上以后反而不顺，所以后来先停下来检查安装位置。调整了轮子和固定位置之间的间隙，再重新紧固，准备继续观察。

现在对左右轮的安装位置还需要再确认，后面要对着资料把四个轮子分清楚。单个轮子能转，还不能说明麦轮底盘就能正常走。

## 后面的制作安排

目前主要做了主控接线、一个电机和一个轮子的尝试。四轮底盘还没有完成，手柄也没有接进来。

机械爪已经看了带舵机的金属夹爪方案，但还没装车，也没有进行抓方块的测试。我们准备先把底盘装起来，确认几个电机能分别正常动作，再接手柄和夹爪。

目前比较费时间的还是接线和安装这些基础问题。前面有时改完一根线没有记下来，再查的时候就要重新看。后面准备把实际接线拍下来，程序也分开保存，至少能知道上一次改了什么。
